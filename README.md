**AI Chat Backend (Node.js + Express + Google Gemini + Pinecone)**

This is the **backend** for the AI Chat App. It provides APIs for sending user messages, generating AI responses using Google Gemini, and storing/searching documents in Pinecone for retrieval-augmented generation (RAG).


🚀 **Features**

➡️Node.js + Express backend with TypeScript
➡️Google Gemini API integration for AI responses
➡️Pinecone integration for embeddings and document retrieval
➡️RAG (Retrieval-Augmented Generation) support
➡️CORS enabled for frontend communication
